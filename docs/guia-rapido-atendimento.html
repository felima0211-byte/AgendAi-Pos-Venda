AgendAI

Como registrar um atendimento

Guia rápido em 5 passos para novos usuários

1

Registre o atendimento

Vá em Atendimentos → Novo Atendimento. Preencha o nome do cliente, serviço realizado, data e valor. Você pode registrar as informações digitando ou usando a gravação de áudio — o AgendAI transcreve automaticamente. Salve para criar o registro.

Atendimentos
2

Gere a mensagem de pós-venda

Após salvar, acesse Pós-Vendas no menu. O AgendAI gera automaticamente uma mensagem personalizada para o cliente com base no serviço registrado. Revise e confirme.

Pós-Vendas
3

Envie a mensagem ao cliente

Copie a mensagem gerada e envie pelo canal de sua preferência (WhatsApp, e-mail, etc.). O sistema registra o envio automaticamente no histórico do cliente.

Chat / Mensagens
4

Acompanhe pelo painel

Em Atendimentos, filtre por status para ver os atendimentos pendentes de retorno. Use os Lembretes para não perder nenhum follow-up.

Lembretes
5

Conclua o atendimento

Quando o cliente confirmar satisfação ou o prazo de retorno encerrar, marque o atendimento como Concluído. O histórico fica salvo no perfil do cliente para consultas futuras.

Concluído
